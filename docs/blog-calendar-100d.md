## 内链规则（每篇必做）

1. **Day N 博客 → Day N 的 3 道菜谱**：在 `relatedRecipeSlugs` 填当天菜谱 slug，详情页自动渲染 "Related Recipes" 卡片（已支持 `RecipeCard`）。
2. **菜谱详情页 → 对应技法/食材博客**：Phase 2 在 `src/data/recipes` 增加 `relatedBlogSlugs` 反向链接（plan 文档 Phase 2）。
3. **合集类（recipes 大类）内链密度最高**：每篇 10 道合集至少内链 8 道已有/将有的菜谱详情页。
4. **锚文本用目标关键词**（英文 canonical 用英关键词，中文镜像用中关键词），不堆砌。

## 发布与验证流程（每日自动化）

见 `haowei-blog-daily` skill：
1. 读日历当日条目 → 生成双语 `BlogPost` 数据（En/Zh 并行字段）。
2. 写入 `src/data/blog/index.ts`（追加到 `blogPosts` 数组）。
3. `tsc --noEmit` + `next build` 验证（NODE_OPTIONS="" 绕过 safe-delete shim）。
4. `git commit` + `git push origin main` → Vercel 自动部署。
5. 发布后 `check-latest-post` 式校验 `/en/blog/{slug}` 与 `/zh/blog/{slug}` 返回 200、canonical/hreflang 正确。
