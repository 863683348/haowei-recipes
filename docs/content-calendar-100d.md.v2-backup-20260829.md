# HǎoWèi 好味 · 100 天菜谱内容规划（种子库 v3 · 366 道 / 19 天 · 10 道/天）

> 目标：在已有 289 道菜谱基础上，继续扩 366 道结构化双语菜谱，建立中餐家常菜 SEO 长尾护城河。
> 本版变更（2026-08-29）：v2 的 236 道（Day 1-81）已全量生成完毕，种子库耗尽；本版为**续集 v3**，从 Day 82 起、节奏提升为 **10 道/天**（原 3 道/天）。
> 原则：**正宗家常菜**（不做美式中餐）、**欧美超市可得或可替代**、每篇含 P0 功能所需结构（英中双语 / 双制计量 / 状态图字段 / termKey / relatedSlugs）。
> **硬去重**：本版所有题目已与现有 289 道菜谱的中文名逐一比对，剔除重复 134 条，确保不与已发布菜谱撞车。
> 自动机制：每日流水线脚本生成当天 10 道 → 自动校验 → 自动提交。
> **v3 取数逻辑变更**：Phase 0 不再按日期推算，改为「取日历中第一个未标记 ✅ 的 Day 行」，生成后在该行追加 ✅（见 haowei-recipe-daily skill）。

## 2. SEO 关键词策略

- **头词**：chinese home cooking recipes、easy chinese recipes、authentic chinese food
- **主题集群（每天 10 道互链）**：每篇菜谱命中 1 个主长尾词 + 2 个次词
- **场景词**：30-minute chinese dinner、chinese comfort food、weeknight chinese meals、air fryer chinese
- **技法词**：how to velvet chicken、how to cook jasmine rice、wok hei explained
- **每篇 Schema**：Recipe JSON-LD + HowTo（步骤级）+ FAQ 联动

## 3. 内容结构模板（每篇必含，P0 功能依赖）

1. 双语标题 / pinyin / 菜系 / 省份
2. 双版本：家庭快手版（默认）+ 餐厅正宗版
3. 食材表：英中双语 + 公制/美制 + category + pantry（local/asian）+ termKey
4. 步骤：≥5 步，关键"看状态"步骤含 stateNote（visual/signal/timeRef/heat）
5. tips / 家庭故事 story（信任要素）
6. dietary 标签 + 饮食限制提示
7. relatedSlugs：同主题日 10 道互链 + 跨日关联
8. 图片：复用项目内已有 webp（按食材主题就近选择），无则 og-default 占位

## 5. 每日自动生产流水线

```
[每日 03:00 定时] 内容流水线脚本
  ├─ 1. 读取日历 → 第一个未标记 ✅ 的 Day 行（10 道菜）
  ├─ 2. AI 生成内容：按 §3 模板产出 10 道完整双语 Recipe 数据
  ├─ 3. 生成器 scripts/recipe-gen.mjs 落盘 + 更新 index.ts
  ├─ 4. 自动补充术语/替换数据
  ├─ 5. 质量闸门：tsc --noEmit → eslint → next build
  ├─ 6. git commit + push（GIT_DIR 模式）
  └─ 7. 在当日行追加 ✅ + 写入 memory 日志
```

**触发方式**：
- A. 手动：说「今天10道菜」→ 按日历下一个未完成任务日执行
- B. 自动：每日 03:00 automation（prompt：「执行 haowei-recipe-daily skill：今天10道菜」）
