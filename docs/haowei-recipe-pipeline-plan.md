## 八、FAQ

**Q: 即梦「60 张/天免费」能直接 API 用吗？**
A: 不一定。60 张/天是**网页端**额度。火山引擎 Ark 的即梦 API 通常是按量付费（新用户可能赠额）。脚本已写好，拿到 `VOLCENGINE_API_KEY` 即可跑；若 API 收费，可改用网页端手动生成 12 张/天（3 菜 × 4）上传，仍是白嫖。

**Q: 每道菜 4 张图怎么分配？**
A: 1 张首页封面（成品，吸引点击）+ 3 张过程图（关键步骤，用于菜谱详情页步骤区）。不是每步 1 张（那样太多且超出免费额度）。

**Q: 视频有没有白嫖方案？**
A: 可灵网页端有免费额度（~66 credits/天），但 API 通常付费。若想纯白嫖，可录屏自己做饭 + 剪映剪辑。AI 生成视频目前无完全免费 API 方案。

**Q: 即梦生成慢不慢？**
A: 即梦 API 通常 10-30s/张。每天 12 张（3 菜 × 4），约 5-10 分钟。脚本内置间隔避免限流。

**Q: 会不会图片太多拖慢网站？**
A: WebP 压缩后单图 80-200KB，每道菜 4 张 ≈ 500KB，对性能影响极小。视频用 `<video preload="metadata">` 懒加载。
